# Contributing

- Conventional Commits (`feat(dbms): …`, `fix(dbms): …`)
- Do not commit `.cursor/` or secrets
- Run lint, check, lint again, unit tests; Rust fmt/check when touching `src-tauri`
- Sync `package.json`, `src-tauri/Cargo.toml`, and `tauri.conf.json` versions on release
- Prefer Wash UI patterns; no em or en dashes in copy
